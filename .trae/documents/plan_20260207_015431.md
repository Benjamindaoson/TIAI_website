# TIAI Website Stage 1 MVP Implementation Plan

Based on your detailed instructions, here is the finalized plan for the TIAI Stage 1 website.

## 1. Technical Architecture 🛠️
*   **Framework**: Next.js 14+ (App Router)
*   **Language**: TypeScript
*   **Styling**: Tailwind CSS
*   **UI Library**: shadcn/ui (Card, Button, Dropdown)
*   **Internationalization**: `next-intl` (English/Chinese)
*   **Deployment**: Vercel Ready

## 2. Directory Structure 📂
```
src/
  app/
    [lang]/
      layout.tsx      (Root layout with i18n provider)
      page.tsx        (Home: Hero + CTA)
      about/page.tsx  (Mission, Governance)
      faculty/page.tsx (Advisors list)
      partners/page.tsx (Why Partner)
      engage/page.tsx (Contact Form)
  components/
    Header.tsx        (Nav + Lang Switcher)
    Footer.tsx        (Contact + Legal)
    Hero.tsx          (Main visual)
    Nav.tsx           (Navigation links)
  i18n/
    request.ts        (i18n config)
  middleware.ts       (Locale routing)
messages/
  en.json
  zh.json
```

## 3. Implementation Steps 🚀
1.  **Setup i18n**: Install `next-intl`, configure middleware and request handler.
2.  **Scaffold Pages**: Create the 4 core pages + Home under `[lang]` route.
3.  **Develop Components**:
    *   **Header**: Bilingual navigation.
    *   **Hero**: "Advancing AI Education" with 2 CTAs.
    *   **Forms**: Simple console-logging form for `/engage`.
4.  **Content Population**: Fill `en.json` and `zh.json` with the provided text.

## 4. MVP Checklist ✅
*   [ ] Bilingual switching works (`/en` <-> `/zh`).
*   [ ] Navigation is fixed and responsive.
*   [ ] All 5 routes are accessible.
*   [ ] Engage form captures input (console log).
*   [ ] Vercel deployment ready.
